# Assets

| Folder | Holds |
| --- | --- |
| [`diagrams/`](diagrams/) | Source files for the diagrams in the videos (one subfolder per chapter, e.g. `diagrams/ch02/`) |
| [`screenshots/`](screenshots/) | Screenshots of external repos shown in the videos |

## Screenshot rules

- Name: `chNN-owner-repo-shot.png`, e.g. `ch02-swe-agent-mini-swe-agent-loop.png`.
- 1920×1080, one browser theme, github.com address bar visible.
- Capture in the week you record; READMEs change.
- Never show tokens, API keys, account menus or private repos.
- Credit `owner/repo` on screen and link it in [REFERENCES.md](../REFERENCES.md).
